Classes vs IDs!


Classes

The class attribute is used to specify one or more class names for an HTML element. The class attribute can be used on any HTML element. The class name in CSS stylesheet using "." symbol.

IDs

The id attribute is a unique identifier that is used to specify the document. It is used by CSS and JavaScript to perform a certain task for a unique element. In CSS, the id attribute is written using the # symbol followed by id.


Why use Classes instead of IDs?

There are times when the developer needs multiple elements to be affected at once. Singling every single element takes not only too much time, but using classes to affect multiple elements is way more effective and optimized.

Syntax for Classes:

<style>

.hello {

font-weight:bold;

}

</style>


<p class="hello">Hello World!</p>


Result:

Hello World!

How to use Classes efficiently

Classes can be given to any element, but you will notice that classes and ids also put a lot of times inside of divs. <div> by itself doesn't mean much, it is a generic box to group things together, but classes and ids benefit a lot from having a neutral box that can wrap whatever target it is they're affecting.

Syntax for <div>use:

<style>

.hello {

font-weight:bold;

}

</style>


<div class="hello">

<p> Hello World!</p>

<p> Now this whole list is pink!</p>

<p> Isn't it cool?!</p>

</div>


Result:

Hello World!

Now this whole list is pink!

Isn't it cool?!

Why use Id instead of class?

Ids are more rigid (one-time use, higher specificity that can make overriding harder later), while classes are flexible and reusable. Regardless, ids are very useful for being faster and simpler than querying by class, and since ids are unique, you know you're getting exactly one specific element.

Syntax for ids:

<!--There are two "Hello World!", each one will be targeted by different ids-->

<style>

#hello1 {

color: pink;

font-weight:bold;

}

#hello2 {

color: blue;

font-weight:bold;

}

</style>


<p id="hello1">Hello World!</p>

<p id="hello2">Hello World!</p>


Result:

Hello World!

Hello World!
